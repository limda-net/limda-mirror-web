Ubuntu Software Repository

{% endraw %}
{% raw %}

This image only contains packages for 32/64-bit x86 architecture processors. For devices with architectures such as ARM (arm64, armhf), PowerPC (ppc64el), RISC-V (riscv64), and S390x (the corresponding official source is ports.ubuntu.com), please use the ubuntu-ports image.

For versions no longer supported by Ubuntu, please refer to Ubuntu Old Release Help.

Before Ubuntu 24.04, Ubuntu's software source configuration file used the traditional One-Line-Style, and the path was /etc/apt/sources.list; starting from Ubuntu 24.04, Ubuntu's software source configuration file has changed to the DEB822 format, and the path is /etc/apt/sources.list.d/ubuntu.sources.

Make a backup of the corresponding files that come with the system, and then replace the corresponding content below according to the format selection, and you can use the selected software source image.

Traditional format (/etc/apt/sources.list)

# The source mirror is commented by default to improve the speed of apt update. You can uncomment it if necessary
deb {{endpoint}}/ {{release}} main restricted universe multiverse
{{src}}deb-src {{endpoint}}/ {{release}} main restricted universe multiverse
deb {{endpoint}}/ {{release}}-updates main restricted universe multiverse
{{src}}deb-src {{endpoint}}/ {{release}}-updates main restricted universe multiverse
deb {{endpoint}}/ {{release}}-backports main restricted universe multiverse
{{src}}deb-src {{endpoint}}/ {{release}}-backports main restricted universe multiverse

# The following security update software sources include official sources and mirror site configurations. If necessary, you can modify the comments and switch them yourself.
{{#mirror_security}}
deb {{endpoint}}/ {{release}}-security main restricted universe multiverse
{{src}}deb-src {{endpoint}}/ {{release}}-security main restricted universe multiverse
{{/mirror_security}}
{{^mirror_security}}
deb http://security.ubuntu.com/ubuntu/ {{release}}-security main restricted universe multiverse
{{src}}deb-src http://security.ubuntu.com/ubuntu/ {{release}}-security main restricted universe multiverse
{{/mirror_security}}

# Pre-release software source, not recommended to enable
{{proposed}}deb {{endpoint}}/ {{release}}-proposed main restricted universe multiverse
{{proposed}}{{src}}deb-src {{endpoint}}/ {{release}}-proposed main restricted universe multiverse
