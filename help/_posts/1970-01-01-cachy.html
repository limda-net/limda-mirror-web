Project Introduction

CachyOS is designed to deliver lightning-fast speeds and stability, ensuring a smooth and enjoyable computing experience every time you use it. Whether you're a seasoned Linux user or just starting out, CachyOS is the ideal choice for those looking for a powerful, customizable and blazingly fast operating system.

Usage

As CachyOS is based on archlinux, first make sure you have configured the system to use our archlinux mirror to get maximum speed:
Limda Host Arch Linux Help

Pacman takes the order of servers in for CachyOS cachyos-mirrorlist as priority, so adding mirrors needs to be added at the top of the file; you can also comment out all other mirrors.

For CachyOS, Edit /etc/pacman.d/cachyos-mirrorlist and add the following to the top of the file:

Server = {{endpoint}}/repo/$arch/$repo



Update the package cache:


{{sudo}}pacman -Syyu



The two ys can avoid problems when switching from a broken mirror to a normal mirror.


If you are switching from a newer mirror to an older one, the following command can downgrade some packages to avoid partial updates of the system.


{{sudo}}pacman -Syyuu
