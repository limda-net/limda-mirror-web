Project Introduction

Arch Linux is a general-purpose x86-64 GNU/Linux distribution. Arch uses a rolling upgrade model and strives to provide the latest stable version of software. The initial installation of Arch is just a basic system, and users can then install the required software according to their preferences and configure it to meet their ideal system.

Usage

Pacman takes the order of servers in mirrorlist as priority, so adding mirrors needs to be added at the top of the file; you can also comment out all other mirrors.

For detailed instructions on using mirrors in Arch Linux, see the official documentation

Edit /etc/pacman.d/mirrorlist and add the following to the top of the file:

Server = {{endpoint}}/$repo/os/$arch



Update the package cache:


{{sudo}}pacman -Syyu



The two ys can avoid problems when switching from a broken mirror to a normal mirror.


If you are switching from a newer mirror to an older one, the following command can downgrade some packages to avoid partial updates of the system.


{{sudo}}pacman -Syyuu
